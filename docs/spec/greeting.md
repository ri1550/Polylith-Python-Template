# Greeting
## Purpose
The greeting domain is the worked example of the spec layer, paired with the example `greeting` component. It shows the shape of a domain file and how a test cites a rule.
Delete this file together with the example bricks (see CONTRIBUTING.md, "If you are setting up the repository").

## Vocabulary
Nothing yet.

## Data
A greeting is one line of text addressed to a name. The name is supplied by the caller and may be blank.

## Behavior rules
1. Greeting a person by name returns a greeting that addresses them by that name.
2. Greeting with a blank name addresses the world instead.
